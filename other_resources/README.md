## Other Resources

### Normalization Tables

This file contains tables with manually normalized and linked variants that we extracted from the XML.
Note that these are only samples from the full dataset, and based on an older version of the dataset, so a variant may not be present anymore.
Because the normalization models that we trained on this also needed to learn when something is too noisy to normalize,
erroneous entries were kept and marked with "Fehler" or "?".
The cluster column was created to speed up the manual process and has been kept for potential further use by new users.

Many thanks to Katrin Fuchs, Aline Vonwiller and Benjamin Hitz for their help to create this resource.
