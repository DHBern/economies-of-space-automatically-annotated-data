# Economies Of Space: Full Annotated Dataset

This repository provides access to the full annotated Economies of Space dataset, presented in BeNASch-XML-format.
Please find further information about the enrichment process in the provided documentation.

## Context

This dataset features over 75'000 register cards from [the Historical Land Records of Basel](https://dls.staatsarchiv.bs.ch/records/1016781),
from the years 1400-1700. The register cards feature information about a number of events surrounding properties in the old city of Basel,
such as property purchases, rent payments and legal proceedings.
You may find more information about the context in [our article about the manually annotated dataset](https://doi.org/10.5334/johd.387).

## Form

This dataset is split into one file per identified street in the old city of Basel.
This keeps most of the XML-files to a size that can be opened, properly highlighted and edited in common editors such as VSCode.
